# Per-function static CPU / instruction cost estimates

This command implements the reporting surface for [issue #692](https://github.com/Centurylong/sanctifier/issues/692).

```sh
sanctifier gas ./contracts/token
sanctifier gas ./contracts/token/Cargo.toml --format json
sanctifier gas ./contracts/token/src/lib.rs
```

Output enumerates public free functions and public methods in `impl` blocks, including inline nested modules, with file-qualified identities and per-function `estimated_instructions` and `estimated_memory_bytes`. Functions are sorted deterministically. Private functions are excluded as separate report rows.

JSON uses `sanctifier-function-cost-v1` with `schema`, `methodology`, `caveat` and `functions`; each function has `file`, `function_name`, `estimated_instructions` and `estimated_memory_bytes`. The `file` is relative to the requested source root. If the supplied path is a Cargo project, only `src/` is scanned; generated target directories and symlinks are skipped.

## Heuristic methodology and accuracy

This intentionally reuses Sanctifier core's AST-based `GasEstimator`, not a second estimator or an ungrounded fee schedule.

| Source operation | Heuristic instruction weight |
| --- | ---: |
| Enter public function | 50 |
| Binary expression | +5 |
| Direct call | +20 |
| Storage `get/set/has/update/remove` method | +1,000 |
| `require_auth` method | +500 |
| Other method call | +25 |
| Loop | Assumes 10 iterations of body |
| Local stack values | Approximate fixed-width/type-name weights |

These are **relative source-level instruction weights**, *not* measured Soroban CPU instructions, fees, XDR/resource usage, gas charges, or validated worst-case bounds. A fixed loop assumption is not a runtime guarantee. Callee bodies, compiler optimization, runtime data, host metering, storage rent and network prices are not measured; reported `estimated_memory_bytes` is a coarse proxy, not peak memory. The method is useful for sorting suspected hotspots but must be calibrated against real compiled execution before making a cost, budget or performance guarantee.

Errors opening source paths or files cause a nonzero command result rather than a misleading zero-cost report. Invalid Rust source currently produces no function rows for that file because `GasEstimator` conservatively returns an empty vector on parse failure; avoid treating an empty report as proof of negligible cost.

## Maintenance

The main CLI command is `sanctifier gas`. Its options are ordinary clap definitions in `tooling/sanctifier-cli/src/commands/gas.rs`, and the generated CLI reference in `docs/cli.md` should be regenerated by the repository's existing documentation generation step when a full dependency-enabled Cargo environment is available. Do not hand-edit the generated help file.
